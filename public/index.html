YouTubeの動画にひらがなで字幕をつけるよ

字幕がみつかりませんでした

MVは画像に歌詞が入ってるから字幕がないことが多いよ。
下の方法で字幕をつけられるよ。

yt-dlp で音声をダウンロードして OpenAI Whisper で文字起こしします。
必要なもの: yt-dlp と プロジェクトの .env に OPENAI_API_KEY=sk-...

費用の目安: 4分の曲 ≈ $0.02 (約3円) ※自分のAPIキーを使用

LRC形式の歌詞を貼り付けてください。
J-Lyrics / UtaNet 等からコピーした LRC テキストが使えます。

例: [00:12.50]夜を越えて　輝いてる

映像フレームを画像認識 (Tesseract OCR) して字幕を取り出します。
MVに歌詞テキストが映像に埋め込まれている場合に試せます。
必要なもの: yt-dlp / ffmpeg / tesseract (+ 日本語パック)

無料 ※ローカル処理・課金なし。4分の曲で1〜3分かかります

brew install tesseract tesseract-lang　または
apt install tesseract-ocr tesseract-ocr-jpn
